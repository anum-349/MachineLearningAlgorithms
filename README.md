## 🔍 Project Descriptions

### 📌 Supervised Learning

1. **🏠 House Price Prediction**

   * Algorithm(s): Linear Regression, Random Forest Regressor
   * Goal: Predict house prices based on features like area, rooms, location.

2. **🚢 Titanic Survival Prediction**

   * Algorithm(s): Logistic Regression, Decision Trees, SVM
   * Goal: Predict survival chances of Titanic passengers using dataset features.

---

### 📌 Unsupervised Learning

3. **🛍️ Mall Customer Segmentation**

   * Algorithm(s): K-Means Clustering, Hierarchical Clustering
   * Goal: Segment customers based on spending score & annual income.

4. **🎬 Movie Recommendation System**

   * Algorithm(s): K-Means, Collaborative Filtering (using MovieLens 100k dataset)
   * Goal: Group users/movies and recommend based on similarity.

---

### 📌 Semi-Supervised Learning

5. **📩 Spam SMS Detection**

   * Algorithm(s): Semi-Supervised Naive Bayes, Self-training models
   * Goal: Detect spam vs. ham SMS messages using partially labeled dataset.

6. **🎵 Spotify Music Analysis**

   * Algorithm(s): Semi-Supervised Clustering, Classification
   * Goal: Analyze and classify music tracks based on audio features.
